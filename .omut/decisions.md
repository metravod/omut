# Decisions

- D1 [accepted 2026-10-31] Agent- and provider-agnostic: state in files, entry through AGENTS.md and the CLI, hooks only as adapters. Rejected: relying on Claude Code mechanisms (auto memory, Tasks, ~/.claude/projects), since people mix agents and hand work between them
- D2 [accepted 2026-10-31] One pack root directory; the lead is any agent started in the root, not a separate program
- D3 [accepted 2026-10-31] Where to keep it, what to commit and how to sync is the user's call; the system only shapes the meta
- D4 [accepted 2026-10-31] The pack view is assembled on read, there is no registry. Rejected: a registry like drift's, which went stale (active projects missing, empty ones listed)
- D5 [accepted 2026-11-01] Project meta: brief / decisions / threads / log in a hidden `.omut/`. Agents get exact paths from the AGENTS.md block, so hiding costs nothing; listings stay clean. Rejected: a visible `lead/`; threads with an `idea` status
- D6 [accepted 2026-10-31] A decision registry instead of owning ADRs: a line with a status and a link to the project's ADR, or a short reason right in the line
- D7 [accepted 2026-10-31] Commands: init, start, freeze, thaw, kill, check, zero; no commands that write meta. kill writes a tombstone instead of scrubbing mentions
- D8 [accepted 2026-11-01] Go, one static binary. Rejected: Python and Node, which pull in a runtime and contradict "no runtime of its own"
- D9 [accepted 2026-11-01] One active writer of the meta; parallel work only with an explicit split of responsibility
- D10 [accepted 2026-11-01] Templates, CLI messages and docs in English; the meta's text is written in whatever language the project's people use, headings and labels stay fixed for `check`
- D11 [open] Make "Where it lives" machine-checkable: optional `probe:` lines (ssh command, URL, cron) run by `check --probe`, so the check against reality is code, not prose in LEAD.md. Against: network and ssh in a tool that has "no network" (spec §11) → threads/review-2026-11-01.md
- D12 [accepted 2026-11-02] A project carries its own rules: `.omut/README.md`, a tool file `zero` keeps current, with a reading guide for visitors and the full rules for those who keep the meta; the pack's `conventions.md` is retired. A pack is optional: `start`, `zero`, `freeze`, `thaw`, `check` work on a single repository. Why: a project is cloned and published without its pack, and the old link `../.omut/conventions.md` led nowhere; GitHub renders the README when someone opens `.omut/`. Rejected: a link to the spec online (agents work offline and don't fetch), keeping both copies (they drift)
- D13 [accepted 2026-11-02] `omut hook start|commit`: one read-only command that agents' and git's hooks call, with per-agent recipes in docs/hooks.md as thin adapters (D1); silent outside any meta, so it can be installed globally. The end of a session is the git commit, not the agent's stop hook: Claude Code, Codex and Cursor fire it after every turn, so a reminder there nags after every answer; uncommitted work is caught at the next start through `stale-brief`. Without git, the signal is the next start ("unrecorded work") and the prose ties recording to "before telling the human it's done". Extends D7. Rejected: a stop-hook reminder; `omut hook install` writing agents' configs (they are the user's files)
- D14 [accepted 2026-11-03] A project with ADRs keeps one registry, not two: with `adr:` in the brief, the ADRs are the registry for the decisions they record, `decisions.md` holds only decisions without an ADR, and `check` reads statuses from the ADR files (frontmatter, a `Status:` line or a `## Status` section; `proposed`/`draft` listed like `open`, stare-decisis `Firmness: tentative` like `doubted`, no status counts as decided). Replaces the `adr-ahead` rule. Why: zymi-core has 46 ADRs and its mirror registry already disagreed with them (ADR-0033); copying every ADR is friction when adopting a repository that has them. Rejected: keeping both and warning on mismatch (the double bookkeeping stays); parsing ADR formats beyond the status line. A mirror registry that exists may stay. Decision of the human → docs/spec-v0.md
